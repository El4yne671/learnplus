Projeto da disciplina de Programação Orientada a Objetos — Semana 2.

## Sobre o sistema
O Learn+ é uma plataforma que permite ao estudante acessar conteúdos, realizar atividades, acompanhar seu desempenho e receber recomendações personalizadas com base nas dificuldades identificadas.
